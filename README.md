# ستايلو (Stylo)

**كل ستايل في مكان واحد** — منصة تجارة إلكترونية للموضة متعددة المتاجر للسوق الليبي (د.ل).

- `mobile/` — تطبيق الجوال (Expo SDK 57، عربي RTL). انظر [mobile/README.md](mobile/README.md).
- `api/` — خادم الـ API (Fastify + PostgreSQL). انظر [api/README.md](api/README.md).
- `database/` — مخطط PostgreSQL (migrations) وبيانات تجريبية.
- [CLAUDE.md](CLAUDE.md) — هوية المشروع وقواعده التقنية.
