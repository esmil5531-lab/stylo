# ستايلو — تطبيق الجوال

**كل ستايل في مكان واحد** — للسوق الليبي، بالعربية واتجاه RTL، والأسعار بالدينار الليبي (د.ل).

مبني على **Expo SDK 57** (React Native 0.86) مع Expo Router و React Query، ويتصل بخادم `api/`. قواعد المشروع الكاملة في [`../CLAUDE.md`](../CLAUDE.md).

## التشغيل

1. شغّلي الخادم أولاً (انظر [`../api/README.md`](../api/README.md)):

```bash
cd api && npm install && npm run db:reset && npm run dev
```

2. ثم التطبيق:

```bash
cd mobile && npm install && npx expo start
```

- امسحي رمز QR بتطبيق **Expo Go** (الجوال والكمبيوتر على نفس شبكة Wi‑Fi)، أو اضغطي `w` للمتصفح، `a` لمحاكي أندرويد، `i` لمحاكي iOS.
- يجد التطبيق الخادم تلقائياً على جهاز Metro عبر المنفذ 4000. لخادم آخر:

```bash
EXPO_PUBLIC_API_URL=https://api.example.ly/v1 npx expo start
```

- `EXPO_PUBLIC_DEV_USER_ID` (اختياري، للتطوير): التصرف كمستخدم آخر من البذور، مثلاً `00000000-0000-0000-0000-000000000005` (مريم، بنغازي) لتجربة فتح سلة مشتركة.

## الشاشات

| المسار | الشاشة |
|---|---|
| `(tabs)/index` | الرئيسية: الشعار، البحث، «لأجلك/ترند/**عروض**/قريب منك»، البانر، منتجات مختارة، **كمّل اللوك**، متاجر مختارة |
| `(tabs)/categories` | الأقسام |
| `(tabs)/cart` | **السلة (متجر واحد)**: «طلبك من …»، **أسرع توصيل / توصيل عادي**، **مشاركة السلة**، إتمام الطلب |
| `(tabs)/wishlist` · `(tabs)/account` | المفضلة · حسابي |
| `products` | نتائج قسم/بحث/خلاصة |
| `product/[id]` | المنتج: المقاسات، الخصم، التوصيل، إضافة للسلة (مع تنبيه المتجر الآخر)، «كمّل اللوك مع هذه القطعة» |
| `look/[id]` | اللوك كاملاً + «أضيفي اللوك كاملاً إلى السلة» |
| `store/[slug]` | صفحة المتجر |
| `shared-cart/[token]` | سلة مشتركة (رابط `stylo://shared-cart/…`) + «أضيفي الكل إلى سلتي» |
| `orders` · `orders/[id]` | الطلبات + مسار الحالات الست |

## كيف تُبنى الواجهة

- `src/api/` — `client.ts` (fetch، مهلة، رسائل أخطاء عربية)، `types.ts`، `hooks.ts` (React Query).
- كل شاشة تعرض التحميل والخطأ مع «إعادة المحاولة» عبر `<QueryState>`.
- **سلة من متجر واحد:** عند إضافة منتج/لوك/سلة مشتركة من متجر آخر يظهر تنبيه بخيارين: «ابدئي سلة جديدة من …» أو «الإبقاء على سلتي الحالية» (`useStoreConflictGuard`).
- الألوان والخطوط من التصميم المعتمد في `src/theme/index.ts` (برجندي عميق `#5B0E2D`، وردي فاتح، Cairo + Cinzel). نسب التباين موثقة أعلى الملف.
- الأسعار تصل بالدرهم وتُعرض عبر `formatPrice()` ← `199 د.ل`.
- صور المنتجات تأتي من الخادم؛ بدون صورة يظهر مربع بلون المنتج وأيقونة القطعة. ارفعي الصور الحقيقية إلى `product_images` و `banners.image_url`.

## ملاحظات

- مشاركة السلة تستخدم `Linking.createURL` فيعمل الرابط في Expo Go (`exp://…`) والنسخة المبنية (`stylo://…`) والويب.
- أندرويد (نسخة development build): الاتصال بخادم `http://` محلي قد يحتاج السماح بـ cleartext؛ استخدمي `https` في الإنتاج.
- مجلدا `ios/` و `android/` يُولَّدان تلقائياً ولا يُرفعان إلى المستودع.
