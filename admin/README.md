# ستايلو — لوحة الإدارة والعمل

تطبيق ويب منفصل عن واجهة الزبون، للمدير العام وموظفي ستايلو وموظفي المتاجر:

- **المتاجر:** إضافة متجر مع صاحبه، والمنطقة، ورسوم التوصيل المباشر بالدينار الليبي، ووقت التجهيز، والحالة (قيد المراجعة / نشط / موقوف).
- **الموظفون والصلاحيات:** إضافة موظف وتحديد دوره. موظف المتجر يرى متجره فقط.
- **السائقون:** إضافة سائق (المدينة، المركبة) ومتابعة توفره: متاح، في توصيلة، غير متصل.
- **الطلبات:** متابعة الطلبات وتحريك الحالات الست، وإسناد الطلب لسائق، والإلغاء مع ذكر السبب.

React 19 + Vite + TypeScript + React Query + React Router، بالعربية واتجاه RTL، وبخط Cairo وألوان ستايلو نفسها.

## كيف تتصل بالبيانات

```
لوحة الإدارة (admin/, :5174)  ──/v1/admin/*──▶  Stylo API (api/, :4000)  ──▶  PostgreSQL
```

- اللوحة **لا تتصل بقاعدة البيانات مباشرة**. كل شيء يمر عبر `/v1/admin/*` في الـ API.
- في التطوير يمرّر Vite طلبات `/v1` إلى `http://localhost:4000` (أو `STYLO_API_URL`).
- في الإنتاج: إما أن تُنشر اللوحة على نفس الدومين خلف نفس الوكيل (proxy)، أو يُضبط `VITE_API_URL` عند البناء.
- الصلاحيات تُفرض في الخادم وليس في الواجهة. الواجهة تخفي فقط ما لا يملكه الموظف.

## التشغيل

شغّلي الـ API أولاً:

```bash
cd api && npm run db:reset && npm run dev
```

ثم اللوحة:

```bash
cd admin && npm install && npm run dev
```

افتحي `http://localhost:5174`.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير على المنفذ 5174 |
| `npm run typecheck` | فحص TypeScript |
| `npm run build` | فحص الأنواع ثم البناء إلى `dist/` |
| `npm run preview` | معاينة نسخة البناء |

## الدخول (مؤقت)

لا يوجد تسجيل دخول بعد. في وضع التطوير يظهر في الشريط العلوي «وضع التطوير — الدخول كـ:» لتختاري أحد حسابات البذور وترَي كيف تتغير اللوحة حسب الصلاحيات:

| الحساب | الدور | ماذا يرى |
|---|---|---|
| مدير ستايلو | مدير عام | كل شيء |
| أحمد الزوي | مدير عمليات | الطلبات، السائقون، المتاجر (دون الموظفين) |
| هدى بن علي | خدمة العملاء | عرض فقط، دون تعديل |
| ريم الترهوني | مديرة «أزياء لورا» | طلبات متجرها فقط: تأكيد، تجهيز، إلغاء |

نسخة الإنتاج (`npm run build`) لا تحتوي هذا المبدّل، والـ API يرفض الطلبات دون تسجيل دخول.
