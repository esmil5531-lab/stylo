# ستايلو — لوحة الإدارة والعمل

تطبيق ويب منفصل عن واجهة الزبون، للمدير العام وموظفي ستايلو وموظفي المتاجر:

- **المتاجر:** إضافة متجر مع صاحبه، والمنطقة، ورسوم التوصيل المباشر بالدينار الليبي، ووقت التجهيز، والحالة (قيد المراجعة / نشط / موقوف).
- **الموظفون والصلاحيات:** إضافة موظف وتحديد دوره. موظف المتجر يرى متجره فقط.
- **السائقون:** إضافة سائق (المدينة، المركبة) ومتابعة توفره: متاح، في توصيلة، غير متصل.
- **الطلبات:** متابعة الطلبات وتحريك الحالات الست، وإسناد الطلب لسائق، والإلغاء مع ذكر السبب.
- **المنتجات والمقاسات:** إضافة منتج وتعديله: السعر والسعر قبل الخصم، ونظام المقاسات (حروف، أرقام، أحذية، أطفال، أو مقاس آخر)، والألوان، والكمية لكل مقاس ولون، وسعر خاص اختياري، وروابط الصور.
- **التقارير والأرباح:** المبيعات، وعمولة ستايلو ونسبتها الفعلية، ومستحقات المتاجر، وإيراد ستايلو، والطلبات، ومتوسط قيمة الطلب، ونسبة الإلغاء، والمبيعات اليومية، والتقرير حسب المتجر مع تصدير CSV، والأكثر مبيعاً.
- **عُهدة المناديب:** النقد الذي حصّله كل مندوب من طلبات الدفع عند الاستلام، وتفصيل صافي استحقاق كل متجر، ثم «تقفيل العُهدة» بتسجيل المبلغ المستلم ووقت الاستلام واسم الموظف، فتعود العُهدة صفراً. سجل كامل لكل تقفيل مع الفرق (نقص/زيادة) وسببه.
- **العمولة للمدير العام فقط:** نسبة العمولة ومبالغها وإيراد ستايلو لا تظهر إلا بصلاحية `finance.view`. الـ API يحذفها من الردود لغير المدير العام.
- **مستحقات المتاجر:** الرصيد غير المسوّى لكل متجر، وإنشاء تسوية لفترة مع معاينتها، ثم تسجيل الدفع برقم الحوالة، وسجل كل التسويات.
- **لوحة المتجر:** كل متجر يدخل بنفس اللوحة بدور «مالك المتجر» ويرى متجره فقط: المنتجات، والطلبات وحالاتها، والتقارير، و«إعدادات متجري».

الأرقام (الهاتف، الأسعار، الكميات، أرقام الطلبات، النسب) تُعرض وتُدخل باتجاه ثابت من اليسار لليمين ولا تنقلب داخل النص العربي. الحقول تقبل الأرقام العربية (٠-٩).

React 19 + Vite + TypeScript + React Query + React Router، بالعربية واتجاه RTL، وبخط Cairo وألوان ستايلو نفسها.

## كيف تتصل بالبيانات

```
لوحة الإدارة (admin/, :5174)  ──/v1/admin/*──▶  Stylo API (api/, :4000)  ──▶  PostgreSQL
```

- اللوحة **لا تتصل بقاعدة البيانات مباشرة**. كل شيء يمر عبر `/v1/admin/*` في الـ API.
- في التطوير يمرّر Vite طلبات `/v1` إلى `http://localhost:4000` (أو `STYLO_API_URL`).
- في الإنتاج: إما أن تُنشر اللوحة على نفس الدومين خلف نفس الوكيل (proxy)، أو يُضبط `VITE_API_URL` عند البناء.
- الصلاحيات تُفرض في الخادم وليس في الواجهة. الواجهة تخفي فقط ما لا يملكه الموظف.

## التشغيل

شغّلي الـ API أولاً:

```bash
cd api && npm run db:reset && npm run dev
```

ثم اللوحة:

```bash
cd admin && npm install && npm run dev
```

افتحي `http://localhost:5174`.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير على المنفذ 5174 |
| `npm run typecheck` | فحص TypeScript |
| `npm run build` | فحص الأنواع ثم البناء إلى `dist/` |
| `npm run preview` | معاينة نسخة البناء |

## الدخول

برقم الهاتف ورمز من 6 أرقام. يُقبل فقط الموظفون وأصحاب المتاجر المفعّلون. الرمز يصل عبر واتساب، وفي وضع التطوير يظهر على الشاشة أيضاً. الحسابات التجريبية:

| الحساب | الدور | ماذا يرى |
|---|---|---|
| مدير ستايلو `0910000001` | مدير عام | كل شيء، ومنها العمولات وتسوية مستحقات المتاجر |
| أحمد الزوي `0910000006` | مدير عمليات | الطلبات، السائقون، عُهدة المناديب وتقفيلها، المتاجر، المنتجات، التقارير (دون العمولة والمستحقات والموظفين) |
| هدى بن علي `0910000007` | خدمة العملاء | عرض فقط، دون تعديل |
| نورة الورفلي `0910000002` | مالكة «أزياء لورا» | متجرها فقط: المنتجات والمقاسات، الطلبات، التقارير، صافي المستحقات (دون العمولة)، إعدادات المتجر |
| ريم الترهوني `0910000008` | مديرة «أزياء لورا» | متجرها فقط: الطلبات والمنتجات والتقارير |

اللوحة على `/admin/` في التطوير (`npm run dev` ⇐ `http://localhost:5174/admin/`) وفي الإنتاج (يقدّمها الـ API على `http://localhost:4000/admin/`).
